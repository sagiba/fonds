# Getting help

- **Questions and bugs:** open an issue using the bug report form. Include your
  Fonds version, how you run it (local CLI, SQLite server, Docker, Neon or another
  host) and a synthetic reproduction. **Never include real financial data,
  screenshots of your accounts or credentials.**
- **Ideas and new provider adapters:** open a feature request first, so the design
  can be agreed before anyone writes code.
- **Security issues:** report them privately as [SECURITY.md](SECURITY.md)
  describes.

Fonds is maintained on a best-effort basis, with no guaranteed response time. It
does not give financial advice: check important figures against your provider's
own records.

There are no published releases yet. When reporting a problem, include the commit
hash you run.
